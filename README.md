# Danmu Hime（弹幕姬）

<img src="desktop/assets/icon.png" width="96" height="96" alt="Danmu Hime 图标">

面向 Bilibili 主播的 Windows 弹幕工具。将直播间弹幕、礼物、进房欢迎和 SC 显示在透明桌面窗口中，也可以通过浏览器源加入 B 站直播姬或 OBS。

桌面预览与浏览器源共享消息、皮肤和布局，调整样式后同步生效。

**当前源码版本：0.8.19** · [版本记录](CHANGELOG.md) · [发布与下载](https://github.com/zerobeyondlogic/danmu-hime/releases)

## 主要功能

- **直播消息**：展示普通弹幕、表情、礼物、上舰、进房欢迎和 SC，区分主播、房管与舰队身份。
- **九套皮肤**：每套独立保存字体、字号、配色、透明度、间距、头像和欢迎设置。
- **灵活排版**：支持顶部／底部对齐、仅显示完整卡片、独立表情缩放和左右留白。
- **样式预设**：将皮肤外观与输出尺寸保存为命名预设，重开后记住上次使用的预设和实际设置。
- **桌面悬浮窗**：支持窗口置顶、鼠标穿透、尺寸锁定和边缘吸附。
- **SC 管理**：按金额计时置顶，可选择永久置顶，也可手动滑动取消置顶。
- **托盘运行**：收起控制台或关闭桌面预览后，浏览器源仍可继续接收弹幕。

## 开始使用

### 安装与连接

从 [Releases](https://github.com/zerobeyondlogic/danmu-hime/releases) 查看可下载版本，安装包版本以对应发布条目为准。需要从当前源码构建时，参见下方“本地开发”。

Windows x64 安装版文件名为 `Danmu-Hime-<版本号>-Setup.exe`，安装后可从桌面快捷方式或开始菜单打开；便携版可直接运行。

1. 打开弹幕姬，输入 B 站直播间房间号并连接。
2. 按需使用 B 站 App 扫码登录，以获取完整用户名及需要登录态的接口信息。
3. 选择皮肤，打开皮肤设置调整外观，并设置输出窗口宽高。
4. 需要在直播画面中显示弹幕时，按下方说明添加浏览器源。

升级前，从托盘菜单选择“退出弹幕姬”，再运行新版安装包。安装范围保持与原版一致，可沿用本机设置和登录态。

### 接入 B 站直播姬或 OBS

1. 保持弹幕姬运行，在直播姬或 OBS 中添加“浏览器”源。
2. 复制弹幕姬控制台“OBS 镜像输出”中的地址，填写到浏览器源。默认地址为：

   ```text
   http://127.0.0.1:38426/desktop/overlay.html?mode=obs
   ```

3. 将浏览器源的**宽度和高度设为控制台显示的尺寸**。首次运行默认是 `515 × 650`，之后以自己的设置为准。
4. 在直播画布中移动、缩放该源，放到需要的位置。

该地址由本机弹幕姬提供，浏览器源应与弹幕姬在同一台电脑上运行。关闭桌面预览或将控制台收起到托盘后，输出继续；退出整个程序后，输出停止。

Windows 显示缩放会影响桌面窗口的物理大小。浏览器源应使用控制台给出的逻辑宽高，再在直播画布中调整显示大小。

## 皮肤与排版

| 皮肤 | 外观特点 |
| --- | --- |
| 轻雾玻璃 | 半透明承载面，可调底色与文字阴影 |
| 映像柔焦 | 以用户头像或礼物图作为背景，图片向文字区域柔和渐隐 |
| 机甲装甲 | 深色装甲、结构线与警示黄切角 |
| 彩色漫画 | 粗墨线对白框、彩色昵称牌与气泡尾 |
| 黑白手绘 | 细线对白框与中文手写字体 |
| Windows 95 | 经典灰色立体边框与深蓝标题栏 |
| 琥珀 EL | 深色背景、琥珀色文字与终端质感 |
| OpenCode TUI | 紧凑的终端消息布局 |
| 轻线描边 | 白色描边、圆体文字与可调阴影 |

皮肤列表默认展示轻雾玻璃和映像柔焦，点击下方箭头可展开全部皮肤。

每套皮肤都能独立调整字体、字号、表情大小、颜色、间距、左右留白、整体比例、背景不透明度，以及头像和进房欢迎。设置实时生效；“恢复这套默认值”可重置当前皮肤。

### 对齐与完整卡片

在各套皮肤设置的“弹幕对齐”中选择：

- **底部对齐**：消息靠下排列，剩余空白留在顶部，默认采用此方式。
- **顶部对齐**：消息靠上排列，剩余空白留在底部。

两种方式显示相同的最近消息，保持原有时间顺序。置顶 SC 位于消息区上方，普通消息在其下方的可用区域内对齐。

“仅显示完整卡片”默认开启，放不下的整张普通消息会隐藏；关闭后，消息区边缘允许显示部分卡片。窗口尺寸、字号或 SC 占位变化时会自动重新排版。

### 映像柔焦

“头像占比”控制右侧图片区域的宽度，范围为 30–70%。占比越大，头像主体越大，裁切也越多。礼物优先显示礼物图标。

“额外显示用户头像”控制左侧的小头像；“承载面不透明度”控制卡片图片背景。普通弹幕、SC 和进房欢迎均使用同套视觉样式。

## 样式预设

调整好皮肤和输出尺寸后，点击“保存当前”并输入名称。以后选择预设、点击“应用”，即可同步切换桌面预览和浏览器源。

预设保存当前皮肤、输出宽高以及这套皮肤的外观、对齐、头像、欢迎和 SC 置顶设置。“管理”中可以改名、用当前样式覆盖或删除预设。最多保存 30 条。

程序会记住上次成功应用或保存的预设。重启或从托盘重开控制台时，自动恢复选中项，并沿用退出前的实际样式。应用预设之后的手动微调也会保留；要将微调写入预设，请使用“覆盖”。

## SC 与消息显示

普通弹幕、礼物和欢迎按接收顺序逐条出场，已有消息平滑上移。消息积压时会加快出场节奏，控制台会显示待显示数量；持续高流量触发积压保护时也会给出提示。

SC 收到后即时置顶，最新一条位于最上方。默认按金额计时，例如 30 元置顶 1 分钟、50 元置顶 2 分钟、100 元置顶 5 分钟。每套皮肤都可以独立开启“SC永久置顶”。

关闭鼠标穿透后，在桌面预览中横向拖动置顶 SC 并松开，可取消置顶。到期或手动取消置顶的 SC 会按最初接收顺序进入普通消息历史。普通消息历史保留最近 48 条，上游撤回和清空操作会移除对应消息。

桌面预览关闭或最小化时，新 SC 可触发系统通知。点击仍有效的通知，可以打开预览并解除鼠标穿透。

## 窗口与托盘

- 拖动桌面预览可移动位置，靠近屏幕边缘时自动吸附。
- 开启“锁定尺寸”可避免误改窗口大小。
- 鼠标穿透开启后，点击会传递给下方窗口；按 `Ctrl + Shift + F10` 可切换穿透状态。
- 关闭控制台时，可选择收起到托盘或退出程序，并记住选择。
- 点击托盘图标可重新打开控制台；彻底退出请使用托盘菜单中的“退出弹幕姬”。

右上角“程序设置”可调整控制台的深色／浅色主题、背景不透明度和关闭行为。

## 常见问题

**连接后没有弹幕**

检查房间号和连接状态。可以断开后重新连接；网络中断时程序也会尝试自动重连。

**浏览器源有空白或大小不合适**

先核对浏览器源宽高是否与弹幕姬控制台一致，再检查直播软件中的缩放、裁剪和边界框。完整卡片模式下，放不下下一张卡片时保留空白属于正常排版。

**文字发糊**

避免先将浏览器源缩得很小，再在直播画布中大幅放大。优先使用与最终显示区域相近的源尺寸。

**桌面窗口无法拖动或调整大小**

需要操作窗口时先关闭鼠标穿透；调整大小时再关闭尺寸锁定。

## 隐私与本地数据

B 站登录 Cookie 保存在本机应用数据目录的 `data/cookies.json`；房间号、窗口位置、皮肤和预设等设置保存在 `desktop-state.json`。

请勿分享登录 Cookie 文件。退出 B 站登录会清除程序保存的登录态。仓库排除了本地用户状态、登录数据、缓存和构建产物。

## 本地开发

建议使用 Node.js 22 或更新的 LTS 版本，在 Windows 上构建安装包。

```powershell
npm ci
npm run desktop
```

```powershell
npm run check          # 语法检查
npm test               # 自动化测试
npm run test:alignment # 九套皮肤的隔离布局验证
npm run dist           # Windows x64 安装版
npm run dist:portable  # Windows x64 便携版
```

构建产物位于 `dist/<版本号>/`。

| 路径 | 内容 |
| --- | --- |
| `desktop/` | 控制台、透明预览、皮肤、设置与消息场景 |
| `js/` | B 站消息协议、头像与表情处理 |
| `server.js` | 本地 HTTP 服务、扫码登录与输出接口 |
| `relay.js` | B 站弹幕连接与消息中继 |
| `test/` | 自动化测试 |
