# Danmu Hime（弹幕姬）

![Danmu Hime 图标](desktop/assets/icon.png)

面向 Bilibili 主播的 Windows 桌面弹幕工具。主播预览窗口是唯一的布局基准，OBS 浏览器源实时镜像同一场景、尺寸与皮肤设置。

> 当前版本：`0.8.19`。项目仍在迭代，发布包暂未进行代码签名，Windows SmartScreen 可能显示未知发布者。更新内容见 [变更记录](CHANGELOG.md)，长时间运行与内存回收检查见 [检查记录](docs/MEMORY-AUDIT-2026-09-12.md)。

本轮全面检查的发现、验证范围与限制见 [检查记录](docs/AUDIT-2026-09-12.md)。

## 主要功能

- 连接直播间后可直接断开，连接或重连中可取消；保留房间号便于再次连接
- 右上角程序设置可切换主界面深色／浅色、调整背景不透明度（30–100%），独立保存且不改变弹幕皮肤
- 透明、可缩放的主播桌面预览，拖到显示器边缘时自动吸附，拖出可见工作区域后自动归位
- 可锁定预览窗口尺寸，锁定后仍能自由拖动位置
- OBS 浏览器源与桌面预览共享同一场景，不再各自重新排版
- 轻雾玻璃、映像柔焦、机甲装甲、彩色漫画、黑白手绘、Windows 95、琥珀 EL、OpenCode TUI、轻线描边九套皮肤
- 首页默认只露出玻璃和映像柔焦，点击卡片下方居中下箭头展开其余七套，上箭头收起；折叠时仍提示当前选中的其他皮肤
- 黑白手绘采用细线圆角对白框和左下曲线气泡尾，使用随程序提供、按需加载的中文手写轮廓字体
- 轻雾玻璃可独立调整承载面颜色，配合不透明度改变底色，并随样式预设保存
- 玻璃与轻线描边可分别调整阴影强度；轻线默认纯白文字、白色描边和系统幼圆字体
- 轻线禁用缺失字重的模拟加粗，避免幼圆部分字出现灰色空心笔画；映像柔焦的时间文字保留原有半透明质感，增加独立深色阴影，便于在浅色头像上阅读
- 每套皮肤可独立调整字体、字号、表情大小、间距、左右留白、颜色、缩放、承载面透明度与头像显示
- 每套皮肤可独立选择“仅显示完整卡片”，默认开启；取消后顶部可显示部分普通消息，SC 仍置顶
- 显示头像时自动补偿窗口宽度，关闭头像后恢复
- 普通弹幕、礼物、上舰和 SC（醒目留言）展示
- 普通消息逐条安排出场，已有卡片平滑上移；短时积压会加快出场节奏，SC 即时置顶
- 兼容新旧礼物推送，支持同一事件中的多份礼物，盲盒按抽中礼物价值显示
- 进房欢迎进入消息列表，不计时消失，随新消息向上滚动；各皮肤可独立开关、调节欢迎字号与两种颜色，桌面预览和 OBS 同步
- 命名样式预设：保存当前皮肤的外观和输出尺寸，快速套用，可改名、覆盖或删除，重启后保留
- SC 即时置顶，默认按金额计时，到期后按原接收顺序进入普通弹幕流；各套皮肤设置中可独立勾选“SC永久置顶”，也可随时在桌面预览滑动取消置顶，回到原消息位置
- SC 最新一条排在最上方，避免旧 SC 堆满后新收到的留言完全落在可见区外
- 同一 SC 的重复推送更新原卡片，上游撤回同步移除；消息已下架或到期后，重送不会再次置顶；上游撤回后不会恢复
- 桌面预览未打开或已最小化时，收到 SC 会弹出系统通知；点击实时横幅或通知中心中仍有效的通知，可打开桌面预览并解除鼠标穿透
- 主播、房管、总督、提督、舰长身份样式
- 可选窗口置顶、鼠标穿透，以及 `Ctrl + Shift + F10` 快速解除穿透
- B 站扫码登录，用于获得完整用户名和登录态接口能力
- 关闭控制台时可选择退出或收起到系统托盘；收起后释放设置窗口，弹幕接收和 OBS 输出继续运行
- 关闭桌面预览会释放预览窗口；消息由主进程处理，只有托盘时仍可向 OBS 输出
- 九套皮肤使用普通 DOM 文字、CSS 与少量静态 SVG，复用未变化的消息卡片；不包含点阵字库、字模解码和点阵画布
- 映像柔焦使用每条消息的头像或礼物图作为右侧图片与模糊背景，只有当前可见卡片加载图片；切回其他皮肤释放背景节点与监听器

## 下载与使用

推荐使用 Windows x64 安装版 `Danmu-Hime-0.8.16-Setup.exe`，安装后从桌面快捷方式或开始菜单打开。程序文件只在安装或升级时解压，之后启动无需重复解压，可减少便携版每次打开前的等待。

升级或从便携版切换前，请先从托盘菜单选择“退出弹幕姬”，完全退出旧版。同一 Windows 用户下会沿用原来的设置和 B 站登录态。

已有安装版时，运行新版 Setup 并保持原安装范围（当前用户或所有用户），会覆盖升级并保留用户数据，无需先手动卸载。目前通过手动运行新版安装包升级，程序尚未实现联网检查和自动下载更新。

1. 输入直播间房间号并连接。
2. 按需要选择皮肤、调整输出窗口并决定是否锁定尺寸。皮肤设置中的“左右留白”默认每侧 8 px，可调 0–64 px，随整体比例缩放；旧设置升级后也会采用更紧凑的默认值。窄窗口会自动收紧过大的实际留白，拉宽后恢复所选值。
3. 在 OBS 中添加“浏览器”源。
4. URL 填写控制台显示的地址，默认是：

   ```text
   http://127.0.0.1:38426/desktop/overlay.html?mode=obs
   ```

5. 将 OBS 浏览器源的宽高设置成控制台显示的主播预览窗口尺寸。首次运行默认是 `515 × 650`。

默认使用轻雾玻璃：整体比例 100%、正文 26 px、用户名 16 px、弹幕间距 10 px、承载面黑色、不透明度 28%；头像和进房欢迎开启，左右留白 8 px、欢迎字号 18 px。其他皮肤的默认值见设计说明。升级保留已保存的个人设置，点击“恢复这套默认值”才应用对应皮肤的新默认外观。

首页皮肤列表每次打开默认折叠，固定显示轻雾玻璃和映像柔焦。卡片下方是一条全宽、30 px 高的窄条，点击居中的双下箭头展开其余七套；展开后箭头朝上，点击收起恢复两套。控件不再显示右下角小字，悬停提示与键盘操作保留。选择其他皮肤后收起，当前皮肤名称在列表下方独立居中显示，不挤偏箭头，也不会自动展开或改变前两套的顺序。

每套皮肤设置中的“表情大小”可调 50–200%，默认 100%，独立缩放普通表情与官方表情，文字字号保持当前设置。调整可实时预览，随皮肤与样式预设保存；恢复该皮肤默认值时回到 100%，旧设置与旧预设也会补为 100%。

玻璃与轻线描边的皮肤设置中有独立“阴影强度”，范围 0–100，默认分别为 60 和 70；0 为关闭，调整会实时预览并随设置与样式预设保存。玻璃原有颜色和字体保持不变。轻线描边默认所有文字为纯白，使用本机“幼圆”（YouYuan）；“底色不透明度”只影响底色，设为 0 时白色描边仍可见，阴影由自己的滑块控制。

首次升级会将轻线中仍等于旧默认值的灰蓝文字逐项换成白色，并将旧默认微软雅黑换成幼圆；自选颜色、字体、字号和尺寸保留。旧预设也按同样规则迁移并保留名称和尺寸；迁移后再手动选用原来的颜色或字体，不会再次被自动替换。

OBS 页面仅包含透明弹幕画布，不会捕捉控制台、窗口边框或桌面拖动手柄。点击“关闭输出窗口”会释放桌面预览窗口，不会中断 OBS 输出；仍可在控制台修改输出宽高和皮肤。点击“显示输出窗口”后按保存的尺寸恢复，并显示当前弹幕及置顶 SC。按钮旁会反馈当前状态，切换期间防止重复点击。

每套皮肤设置中的“仅显示完整卡片”默认勾选：普通弹幕、礼物与欢迎只显示能完整放入消息区的卡片，顶部放不下的整张隐藏。取消勾选后，顶部允许显示半张或部分普通消息，仍在置顶的 SC 不受影响，到期 SC 则遵循普通卡片规则；逐条出场和平滑上移动画保持不变。各套独立保存，支持实时预览、恢复默认与样式预设，旧设置和旧预设自动补为开启。调整窗口、字号或下架 SC 后自动重新计算；隐藏消息保留在最近历史中，有空间时可以恢复显示。映像柔焦的完全隐藏卡片会释放背景图层。

普通弹幕、礼物和欢迎先进入有上限的待显示队列，再按统一时序逐条安排出场，桌面与 OBS 共享同一已出场场景。新消息进入时，已有卡片平滑上移；短时流量升高会加快节奏，SC 不等待普通队列，直接置顶。待显示消息与最近 48 条已出场普通消息分别保存，短峰值不会仅因历史达到 48 条而把尚未安排出场的消息挤掉。

控制台连接状态附近会在积压时显示“待显示 N 条”；若待显示队列超过数量或字节上限，会启用积压保护，并显示“积压保护已跳过 N 条”。提示仅在控制台显示，计数随清空场景或换房重置。持续高流量仍可能排队或触发跳过；出场调度也不保证每条消息在任何尺寸、字号与 SC 占位下都能完整阅读。

没有桌面或 OBS 输出页订阅时，不积累待播放的旧队列，只维护有限的最近消息；之后打开输出页面时直接加载当前场景，不从头重播这段时间的消息。

各套“皮肤设置”中的“弹幕对齐”可切换顶部／底部对齐，默认底部对齐，分别保存并随样式预设恢复。两种对齐显示相同的最近消息，时间顺序不变；开启“仅显示完整卡片”时，顶部对齐将放不下下一张完整卡片的剩余空白留在底部。置顶 SC 保持原位，普通消息在其下方可用区域对齐。桌面预览、OBS 和 B 站直播姬浏览器源同步生效。

SC 置顶相当于“上架”，到期或手动划掉相当于“下架”。先关闭鼠标穿透，再横向拖动置顶 SC 并松开，桌面和 OBS 会同步取消置顶，保留卡片并回到最初收到时的弹幕位置。置顶 SC 整个卡片区域均接收滑动，包括轻雾玻璃的透明空白处；锁定尺寸只限制用户缩放，不限制 SC 滑动或窗口移动。已经下架的 SC 像普通消息一样向上滚动，其区域恢复拖动窗口，不再接受重复下架。未达到滑动阈值或手势取消时，卡片回到原置顶位置。

“SC永久置顶”放在每套皮肤设置中，默认不勾选；各套独立记忆，并随该皮肤的样式预设保存。桌面与 OBS 使用当前皮肤的选择。旧版已开启全局长期显示时，升级会让尚无独立选择的皮肤沿用开启，已明确设置的每套开关保留；旧预设缺少此项则按默认不勾选补齐。未勾选时，SC 从弹幕姬本机收到的时刻开始计时：

| SC 金额 | 置顶时长 |
| ---: | ---: |
| 2 元 | 5 秒 |
| 30 元 | 1 分钟 |
| 50 元 | 2 分钟 |
| 100 元 | 5 分钟 |
| 500 元 | 30 分钟 |
| 1,000 元 | 1 小时 |
| 2,000 元 | 2 小时 |

档位之间按线性比例计算，低于 2 元至少置顶 5 秒，金额缺失或无效时为 1 分钟，高于 2,000 元沿最后一段比例延长。到期或手动下架只取消置顶，保留 SC 金额、内容、头像与原时间，回到最初收到时对应的弹幕位置，再随其他消息上移；按本机接收先后排序，时间戳相同也能保持顺序，不会按到期时间重新插到最底部。下架 SC 与普通消息共用最近 48 条历史上限，原位置已超出历史时自然淘汰。上游撤回与清空仍真正移除。勾选后保留当前仍在置顶的 SC；再次取消勾选或切换到按金额计时的皮肤时，按原接收时刻重算，已超时的立即进入弹幕流。补包与金额修正不重置计时，已下架 SC 不会因重新勾选或切换皮肤而重新置顶，已移除内容不恢复。

桌面预览关闭、隐藏或最小化时，新收到的 SC 会触发系统通知；多条 SC 累计计数，最多保留一条待处理提示。系统通知不可用时尝试托盘气泡提示。程序运行期间，点击实时横幅，或横幅收起后在 Windows 通知中心点击仍有效的 SC 通知，都可打开或恢复桌面预览、解除鼠标穿透，并显示当前置顶 SC。已到期、已下架、已清除或被新提示替换的旧通知会主动移除；点击通知不会恢复已删除的 SC。通知只负责提醒，没有点击时不会自动创建桌面预览窗口。桌面预览已可见时无需额外通知。

首次加载 OBS 浏览器源前，请先打开弹幕姬。若 OBS 仍开着 `0.4.0` 或更早版本的页面，安装本版后需手动刷新该源一次，加载新的恢复逻辑。此后页面保持打开时，弹幕姬重启或本地连接中断后会自动重连并接收当前场景；检测到程序版本变化时才重新加载资源，不会周期性刷新。这是源页面自行恢复，不会操作 OBS 按钮，也不是联网更新弹幕姬。

盲盒礼物金额显示抽中礼物的单价乘以本次数量，抽中价格缺失时不显示金额；普通礼物和 SC 沿用原金额规则。

同一次上舰的购买通知与新旧支付通知会合并到同一张卡片，保留正确的 UID、头像和舰队等级。金额以支付通知的实际单价 × 数量为准，不使用购买通知里的原标价；若只收到购买通知，先显示上舰内容，收到有效支付金额后在原位置补齐。不同支付流水保持独立，同一流水的重复支付通知不重复显示。

收到 B 站推送的进房通知时，“欢迎 XXX 进入直播间”会作为一条消息进入列表，与弹幕、礼物按接收顺序排列。欢迎不再计时消失，也不再占用固定底部区域；后续消息会将它向上推，超出画面后不可见，并与普通消息、到期 SC 共用最近 48 条历史上限，未到期 SC 仍独立置顶。欢迎使用当前皮肤的字体、颜色和紧凑承载面，不另加头像或另一种弹窗样式。每套皮肤可独立开关“进房欢迎”、调整“欢迎字号”（12–48 px，默认 18 px，随整体比例缩放）以及提示文字和昵称颜色，这些设置都纳入样式预设。关闭期间不记录新的欢迎；已在历史中的欢迎会隐藏，重新开启可显示尚未被新消息移出的记录。旧设置和预设自动补齐欢迎字号，移除旧底部间距参数。显示范围取决于 B 站实际推送的进房通知。

点击控制台右上角的关闭按钮，或按 `Alt + F4`，弹窗横向提供“最小化到托盘”和“退出程序”两个按钮；点击弹窗的 × 或按 `Esc` 取消。勾选“记住我的选择”后，下次关闭会直接执行选定动作；可点击右上角齿轮，在“程序设置”中的“关闭主窗口时”修改，也可恢复“每次询问”。关闭方式的展开菜单与程序设置采用一致的深色样式，支持鼠标选择和键盘操作。

收起到托盘会保存设置并释放控制台窗口；桌面弹幕预览和 OBS 输出仍按原设置运行。点击任务栏右下角的弹幕姬图标，或右键选择“打开控制台”，即可恢复设置窗口；右键菜单中的“退出弹幕姬”会结束整个程序。普通最小化按钮仍将窗口最小化到任务栏。

## 样式预设

先调整好皮肤、窗口尺寸与配色，再在首页“样式预设”中点击“保存当前”，输入名称。以后从列表选择预设并点击“应用”，桌面预览和 OBS 会同步切换。

成功应用或保存当前样式后，程序记住该预设。重启或从托盘重开控制台时自动恢复选中项，输出沿用退出前的实际设置，包括应用预设后手动调整的字号、对齐和尺寸；无需再次点击“应用”。只浏览下拉框而未应用，不会替换上次使用记录。重命名保留记录，删除该预设只清除选中项、不改变当前样式。旧版本未记录预设身份时，会按已保存的皮肤参数与输出尺寸恢复唯一匹配项；不匹配或存在多个相同样式时保持未选择。

预设包含保存时选中的皮肤、输出宽高和这套皮肤的字体、字号、表情大小、间距、颜色、透明度、头像、进房欢迎、“仅显示完整卡片”与“SC永久置顶”选择；玻璃和轻线描边还保存各自的阴影强度。它不改变其他皮肤、直播间、登录状态、窗口位置、置顶、穿透、关闭方式或预览开关；关闭桌面预览时也可套用，显式套用可更新已锁定的窗口尺寸。旧黑白手绘预设中的方条／椭圆字段自动忽略，原有字体、字号、配色、名称和尺寸继续保留。

“管理”中可以改名，或用当前样式覆盖已有预设；删除需要再次点击确认。临时调整样式不会自动改写已保存的预设。预设保存在本机，最多 30 条，每个名称最多 40 字。

## 尺寸与 Windows 缩放

控制台显示的是预览窗口内部的逻辑尺寸，不包括 Windows 窗口阴影和不可见边框。Windows 的 100%、150% 等显示缩放会影响桌面上的物理大小，但 OBS 仍按控制台给出的逻辑宽高渲染。要让两边一一对应，请让 OBS 浏览器源使用相同的宽高，并避免在 OBS 中对源做非整数比例的二次缩放。

### 版本维护

交付内容有变化时递增版本号；同一内容的安装版和便携版共享版本号。后续小修复可先运行以下命令，再同步本文版本、安装包文件名及 [变更记录](CHANGELOG.md)，最后检查、测试和打包：

```powershell
npm version patch --no-git-tag-version
```

此命令只更新 `package.json` 和锁文件。用户确认版本后，完成版本号与变更记录同步、检查、测试和打包，将对应改动提交并正常推送到当前分支的跟踪远端，同时创建并推送 `v<版本号>` 标签。这是持续授权，无需再次询问是否推送；普通开发改动不自动视为已确认版本。

不强制推送，不改写已有版本标签；凭据、本地状态和构建产物不提交到 Git。此流程同步 Git 分支和标签，不自动创建 GitHub Release 或上传安装包。

## 映像柔焦皮肤

选择“映像柔焦”后，普通弹幕、SC 与进房欢迎以发送者头像作为卡片背景。皮肤设置中的“头像占比”控制右侧图片区域占卡片宽度的比例（30–70%，默认48%）；数值越大，头像主体越大、裁切越多，64%可恢复早先普通卡片的头像宽度。图片居中铺满该区域，向左通过同图模糊渐隐承载文字。礼物优先采用实际礼物图标并完整居中显示，旧礼物消息只有 ID 时按需查询图标目录；图标缺失或加载失败时回退到头像，仍不可用则保持深色底，正文不会消失。头像占比支持实时预览、保存、恢复默认与样式预设。

默认关闭额外的小头像；皮肤设置中的“额外显示用户头像”只控制左侧小头像，背景图片不受影响。“承载面不透明度”控制整张图片背景，设为 0 会移除背景并停止它的图片加载。图片只为当前可见卡片挂载，离屏、关闭预览、切换皮肤或页面离开后释放；背景最多同时加载四条，复用已有图片代理缓存。映像柔焦在皮肤列表排第二，其余保留皮肤的个人设置不变。

V2 进房欢迎直接使用原消息携带的头像，头像查询接口暂时不可用时仍能显示背景；只有原消息缺少头像时才尝试补查。

## 新增卡片皮肤

- **机甲装甲**：海军蓝装甲、军绿结构线与警示黄切角，普通文字保持亮白；礼物、SC 与欢迎共用装甲轮廓。
- **彩色漫画**：圆角与曲线尾巴共用一条完整闭合的粗墨线轮廓；普通消息白底黑字、蓝色昵称牌白字，SC 使用黄色卡片，礼物保留红色金额牌，身份通过文字标签表达。
- **黑白手绘**：白底细线圆角对白框，左下连接曲线气泡尾；昵称、身份和正文均放在框内，使用中文手写字。新用户默认关闭头像，已有显式设置和预设保留原选择；开启后显示头像原色。原有字体、字号、配色和头像设置继续有效。
- **Windows 95**：经典灰色立体边框、深蓝标题栏白色昵称、白色正文区黑字；所有元素只是消息外观，不添加无功能的关闭、最小化或菜单按钮。

四套皮肤均保留独立头像、欢迎、字体、字号、颜色与透明度设置；普通弹幕、礼物、SC 和欢迎采用同套视觉语言，完整卡片规则、SC 操作与 OBS 同步保持一致。旧暖纸札记自动迁移到玻璃，保留现有玻璃设置；原暖纸预设保留名称、ID 和输出尺寸，外观改用玻璃默认值。旧黑白简报继续迁移到玻璃，不会自动改成黑白手绘。

## 隐私与本地数据

- B 站扫码登录产生的 Cookie 只保存在本机应用数据目录的 `data/cookies.json`。
- 房间号、窗口位置、皮肤等设置保存在本机的 `desktop-state.json`。
- `data/`、构建目录和临时文件已被 Git 忽略，不会提交到仓库。
- 请勿分享 `cookies.json`；它包含你的 B 站登录凭据。退出登录会清除应用使用的登录态。

## 常见问题

**连接后没有弹幕**

先确认直播间房间号有效。程序重启后如果控制台仅显示已保存但实际未连接，点击“重新连接”。网络中断时中继会自动尝试恢复。

**OBS 四周有透明空白**

检查 OBS 浏览器源宽高是否与控制台一致，并在“变换”中重置源，避免遗留裁剪、边界框或非等比缩放。

**OBS 字体发糊**

优先使用与场景匹配的浏览器源分辨率，并在 OBS 内按整数比例显示。先缩小浏览器源再放大，会把已经栅格化的文字一并放大。

**桌面预览无法拉伸**

关闭“锁定输出窗口尺寸”。如果只看到位置变化而画面没有重排，先确认运行的是最新 Release。

**出现 No content under offscreen mode**

这是 Electron 离屏窗口被错误显示到桌面时的提示，已定位到开发截图测试窗口误显示。正式弹幕窗口未开启离屏模式；测试工具已加防护，避免测试窗口再被显示。这不是 B 站礼物或弹幕接口错误。

## 字体与授权

0.6.0 已移除 GNU Unifont 与 Fusion Pixel 字库及其绘制模块；当前不包含点阵字库、字模解码或点阵画布。旧点阵自动替换为琥珀 EL；旧黑白简报、Risograph 与暖纸札记都迁移到轻雾玻璃，采用替代皮肤的默认外观。已有玻璃设置优先保留；旧预设保留名称、ID 和输出尺寸，其他保留皮肤的有效自定义设置不变。

黑白手绘默认使用随安装包提供的 **ZCOOL KuaiLe** 静态轮廓字体，WOFF2 文件为 **871,928 字节**。它包含完整的上游常用字集，覆盖全部 6,763 个 GB2312 汉字；未包含的生僻字、部分繁体字和表情使用系统字体回退。仅在选择黑白手绘且实际使用该字体时按需加载本地文件，其他皮肤不注册或请求它；没有远程字体下载，也不是只含演示文字的子集。其余皮肤默认使用本机字体。

该字体遵循 **SIL Open Font License 1.1**，授权和来源说明分别见 [OFL.txt](desktop/fonts/zcool-kuaile/OFL.txt) 与 [SOURCE.md](desktop/fonts/zcool-kuaile/SOURCE.md)。字体文件大小不等于运行时内存占用。

轻线描边的幼圆（YouYuan）只调用系统已安装字体，不随程序打包或下载。部分 Windows 电脑没有幼圆时会回退到微软雅黑或其他系统中文字体，因此不同电脑的字形可能有所区别。

源码中涉及旧点阵名称的判断仅用于设置迁移，不能重新启动点阵渲染。登录二维码仍需二维码库；旧网页版庆祝特效也仍供该页面使用，两者均不是点阵皮肤残留，桌面与 OBS 输出不会加载旧网页版特效。
